# Basemap data and attribution

Built by `tools/basemap/build.sh`. Protomaps build used: see `BUILD`.

| File | Source | License / attribution |
|---|---|---|
| `us-core.pmtiles` | [Protomaps Basemap](https://docs.protomaps.com/basemaps/downloads) daily build, extracted for the US | Data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright) (ODbL); Natural Earth (public domain) |
| `counties-lines.geojson`, `counties-labels.geojson` | US Census Bureau cartographic boundary files, 1:500k counties | Public domain |
| `fonts/` | Noto Sans glyphs from [protomaps/basemaps-assets](https://github.com/protomaps/basemaps-assets) | SIL Open Font License 1.1 |
| `sprites/` | Protomaps sprites v4 from [protomaps/basemaps-assets](https://github.com/protomaps/basemaps-assets) | See that repository |

The map shows "© OpenStreetMap" in its attribution control, as the ODbL requires.
